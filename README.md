## Project Description

PathLab – Pathology Laboratory Management System is a web-based application used to manage patient details, laboratory test bookings, sample collection, and test reports. This project focuses on testing the existing application by preparing test plans, designing and executing test cases, identifying defects, performing automation testing, and maintaining all testing documents, screenshots, and reports in a GitHub repository.

## Objectives of the Project

1. To understand the modules and functionalities of the PathLab application.
2. To prepare a test plan and design test cases using suitable testing techniques.
3. To execute test cases and record actual results.
4. To identify and document software defects.
5. To perform additional testing using tools such as JUnit, Selenium, or Postman.
6. To prepare test execution summaries and maintain all project deliverables in GitHub.
7. To demonstrate the testing process and results to faculty.
